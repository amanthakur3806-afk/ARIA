# ARIA — AI Revision & Intelligent Assistance

ARIA is an AI-powered study assistant designed to help students understand their course materials, remember learning preferences, and manage revision tasks.

This project is developed by a team of three to learn Git, GitHub collaboration, and modern AI application development.

## Problem Statement

Students often struggle to organize study materials, find relevant information in their notes, and keep track of revision tasks. Traditional chatbots may not remember previous interactions or provide answers based on the student's own course materials.

ARIA aims to solve these problems by combining document-based question answering, persistent memory, and AI-powered task management in one application.

## Key Features

- **AI Study Assistant:** Ask questions and receive explanations of academic topics.
- **RAG (Retrieval-Augmented Generation):** Retrieve relevant information from uploaded study materials to generate context-aware answers.
- **Persistent Memory:** Remember useful learning preferences and retain information across sessions.
- **MCP (Model Context Protocol):** Enable the AI assistant to interact with tools for managing revision tasks.
- **AI Agent:** Coordinate document retrieval, memory access, and tool usage based on the user's request.
- **Task Management:** Create, view, and complete revision tasks.

## Technology Stack

- **Python** — Core application development
- **Streamlit** — User interface
- **LangGraph** — AI agent workflow orchestration
- **Chroma** — Vector database for document retrieval
- **SQLite** — Persistent application data and memory
- **MCP** — Integration with tools and actions
- **Git and GitHub** — Version control and team collaboration

## Project Goal

The goal of ARIA is to build a simple but functional AI study assistant while learning how multiple developers can collaborate on a shared software project.

The project demonstrates how an AI agent can combine RAG, persistent memory, databases, and external tools to solve a practical problem.

## Team

This project is developed by a team of three members:

- **Member 1:** RAG and document retrieval
- **Member 2:** Database and persistent memory
- **Member 3:** AI agent and MCP integration

All members collaborate on integration, testing, code reviews, and documentation using GitHub.

## Project Status

Currently under development. Features will be implemented incrementally, tested, and integrated through Git branches and pull requests .
